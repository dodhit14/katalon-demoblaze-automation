# Katalon Studio Overview

## Apa itu Katalon Studio
Katalon Studio merupakan salah satu platform automation testing berbasis Selenium dan Appium yang menyediakan antarmuka berbasis GUI (Graphical User Interface) dengan beberapa fitur bawaan yang dapat  mempermudah proses pembuatan automation tanpa harus membuat framework dari awal.

Project ini menggunakan Katalon Studio sebagai tools utama untuk membuat automation testing pada website Demoblaze.

## Alasan memilih Katalon
- Katalon Studio memiliki fitur yang dapat digunakan untuk memahami struktur project automation secara bertahap, fitur yang dimaksud seperti :
  Spy Web
  Record Web
  Object Repository
  Test Suites
  Data Files
  Report
- Memungkinkan  untuk fokus membangun mindset QA dan konsep automation tanpa membangun framework dari awal.
- Membantu memahami hubungan antara proses Manual Testing dengan Automation Testing melalui implementasi testcase yang sama.
- Mendukung penggunaan GUI maupun Command Line Interface (CLI), sehingga project yang dibangun dapat dikembangkan menuju implementasi CI/CD di tahap selanjutnya.
