# Katalon Automation Practice - Demoblaze

This repository contains my automation testing practice project using **Katalon Studio**. The project was created as part of my preparation for obtaining the **Katalon Practitioner Certification** while improving my automation testing skills.

## Project Overview

The automation scenarios are built based on the Demoblaze web application and focus on fundamental web automation concepts, including data-driven testing and test suite management.

## Tech Stack

- Katalon Studio 11.1.3
- Groovy
- Chrome Browser

## Implemented Features

Currently, the project covers the following scenarios:

- User Registration
- User Login

More automation scenarios will be added as my learning progresses.

## Testing Techniques

The project currently implements:

- Data-Driven Testing
- Test Suite Collection

## How to Run

1. Clone this repository.

```bash
git clone https://github.com/dodhit14/katalon-demoblaze-automation.git
```

2. Open the project using **Katalon Studio 11.1.3**.

3. Select a **Test Suite** or **Test Suite Collection**.

4. Click **Execute** to run the automation tests.

## Learning Objectives

This project aims to:

- Practice web UI automation using Katalon Studio.
- Learn automation test organization and best practices.
- Apply Data-Driven Testing in real test scenarios.
- Manage test execution using Test Suite Collection.
- Prepare for the Katalon Practitioner Certification.
