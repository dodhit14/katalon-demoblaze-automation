This repository contains my web automation testing practice project using **Katalon Studio**. The project was created as part of my preparation for obtaining the **Katalon Practitioner Certification** while improving my automation testing skills.

---

## Project Overview

The automation scenarios are built based on the **Demoblaze** web application and focus on learning fundamental web automation concepts, project organization, and automation best practices using Katalon Studio.

## How to Run

1. Clone this repository.

```bash
git clone https://github.com/dodhit14/katalon-demoblaze-automation.git
```

2. Open the project using **Katalon Studio 11.1.3**.

3. Select a **Test Suite** or **Test Suite Collection**.

4. Click **Execute** to run the automation tests.
